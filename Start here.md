# Start here
**Ctrl + Alt + Q** opens the capture menu. **Ctrl + Alt + D** opens today's work note. Use this only when it helps; there is no daily routine to maintain.

## Tasks
Capture a **Task** with an optional due date. [[00 Inbox/Task inbox|Tasks]] shows only open captures; [[Home]] also includes tasks in work logs and project notes.
When you tick a task, it disappears from the active lists immediately. [[00 Inbox/Task history|Completed tasks]] keeps the most recent 100 completed captures; all records remain in task storage and are searchable. Nothing is deleted.
Use **Tasks: Create or edit task** from Ctrl + P for scheduled dates, recurrence, or priority. **Ctrl + Enter** toggles completion and records a done date.
For someone else's dependency, add **#waiting** and their name to the task.

## Notes inbox
**Quick note** adds a timestamped capture at the top of [[00 Inbox/Notes inbox|Notes inbox]]. Newest first. Move useful knowledge into a proper guide when you need it again.

## Work log
**Today's work note** is just a dated page with:
- **Doing / pending** — your checkboxes for this work session.
- **Blockers** — what is stopping you.
- **Ask / explore** — questions and things to investigate.
Add new checkboxes under Doing / pending. Unfinished work remains visible on Home, including tasks from earlier work logs. It is not copied into each new day. Existing notes are opened without replacing your writing.
There are no sprint dashboards or mood forms in the work log.

## Retro points
One current retro lives directly in **02 Retros**.
1. Use **Retro point / feeling** to jot down something you want to discuss. The feeling prompt is optional. It goes straight into the current retro, newest first.
2. Use **Open current retro** to read or edit it. Tick discussion points when discussed. Add concrete actions separately under Follow-up actions.
3. At the next sprint, choose **New retro** and give it a name, such as *Sprint 3*. The previous retro moves into **02 Retros/Archive**, with its contents intact.
If no retro exists yet, your first capture creates one automatically. There is no sprint scheduling, hub, current-sprint pointer, or separate retro inbox.
Older discussion points stay with their archived retro. Copy a point into the new note yourself if it still matters.

## Knowledge and other notes
Choose a **Deployment runbook**, **Local testing guide**, **Business / domain knowledge**, **Decision**, **Meeting**, **Project / initiative**, or **Misc note**. The menu fills the title/date, files it in the right folder, and opens it in edit mode with the editor focused.
All sections are optional. Templates are in **90 Templates**. Guides start as **draft**; after checking, set **status** to **verified** and record sources, owner, and review date. Link related notes with double brackets.
Keep real tickets in the team's tracker and use these notes for context, learning, and reminders.

## Plugins and storage
[Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) supplies live task views; [QuickAdd](https://github.com/chhoumann/quickadd) handles capture and templates. Daily notes, Templates, Bases, Search, Bookmarks, and Backlinks are built in.
**99 System/Tasks** stores captured task records so the inbox remains clean. **97 Archive** is available for other old work. Backup/sync is not configured.

## Move to your company laptop
1. Extract the complete ZIP into a permanent folder on the company laptop. Keep the hidden **.obsidian** folder.
2. In Obsidian, choose **Open folder as vault** and select the extracted folder.
3. Enable Tasks and QuickAdd when prompted, subject to company policy.
4. Press **Ctrl + Alt + Q** to check the capture menu. **Ctrl + Alt + D** creates your first work note.
This copy starts with empty inboxes, task history, work logs, retros, archives, and knowledge folders. Your first retro capture creates a note automatically.
