# Office Brain
**Ctrl + Alt + Q** captures tasks, notes, and retro points. **Ctrl + Alt + D** opens a simple work note for today.

## Open work
Pending tasks stay here until done, even if you skip a work log.

```tasks
not done
path does not include 90 Templates
path does not include 97 Archive
path does not include /Archive/
tags do not include #retro
tags do not include #waiting
sort by priority
sort by due
group by filename
limit 30
```

## Waiting / blockers
Add **#waiting** to a task that depends on someone else.

```tasks
not done
path does not include 90 Templates
path does not include 97 Archive
path does not include /Archive/
tags do not include #retro
tags include #waiting
group by filename
limit 15
```

## Retro points
**Ctrl + Alt + Q → Open current retro** opens your current note. **New retro** starts the next one and moves the previous note into **02 Retros/Archive**.

```tasks
not done
path includes 02 Retros/
path does not include /Archive/
tags include #retro
```
